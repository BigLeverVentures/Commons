# License preservation

These directories copy license/notice files from the installed lockfile-selected direct packages and Supabase client subpackages. They do not replace the package's own notices. Packages can embed further dependencies with their own notices; preserve those notices in installed modules and deployment output. The npm lockfile records dependency versions and integrity but is not a license grant.

Local font licenses remain in `public/fonts/Inter-OFL.txt` and `public/fonts/Fraunces-OFL.txt`; PDF.js's Apache 2.0 text remains in `public/pdfjs-LICENSE.txt`. `lucide.txt` is retained with the copied icon material. See the root THIRD_PARTY_NOTICES.md for illustration provenance and unresolved decorative-artwork rights.
